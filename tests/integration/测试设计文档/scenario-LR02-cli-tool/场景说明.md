# LR02 CLI 工具功能验证

## 1. 场景背景与目的

`bfe-pblog-tool` 是 `log-reader` 仓库的第二个构建产物，提供命令行方式离线查看 BFE protobuf 访问日志的能力。它包含两个子命令：

- `cat`：全量输出日志文件中的所有记录，支持 `-n` 显示行号。
- `tail`：输出日志文件末尾 N 条记录，支持 `-f` 持续跟随新增数据。

本场景验证：

- `bfe-pblog-tool cat` 能正确输出日志文件中的所有记录，且行号显示正确。
- `bfe-pblog-tool tail` 能正确输出指定数量的末尾记录，默认数量为 10。
- 两个子命令对不存在的文件能正确报错。
- 两个子命令对空文件能正确处理（不崩溃，输出为空）。
- `bfe-pblog-tool tail -f` 能持续跟随并输出新增数据。

## 2. 运行模式

- **命令行模式**：编译 `bfe-pblog-tool` 二进制文件，在测试代码中通过 `exec.Command` 调用它，传入测试 pb 日志文件路径作为参数。
- 不涉及真实 BFE、不涉及 Kafka、不涉及 `log-reader` daemon 进程。
- 测试数据通过 `common.LogGenerator` + `common.MakeRequestLog` 生成。

## 3. 涉及的配置文件

本场景不涉及配置文件。CLI 工具直接读取命令行参数指定的 pb 日志文件。

## 4. 测试例列表

| 编号 | 名称 | 核心验证点 |
|------|------|------------|
| TC-01 | cat 基本输出 | `cat` 全量输出 9 条记录，stdout 以 "Time taken:" 结尾 |
| TC-02 | cat 带行号 | `cat -n` 每条记录前带递增行号，共 9 条数据行 |
| TC-03 | cat 不存在的文件 | 文件不存在时返回非零退出码，stderr 包含错误信息 |
| TC-04 | cat 空文件 | 空文件返回零退出码，无记录输出 |
| TC-05 | tail 默认输出 | `tail` 默认输出最后 10 条（文件只有 9 条则全部输出） |
| TC-06 | tail 指定条数 | `tail -n 3` 只输出最后 3 条记录 |
| TC-07 | tail 不存在的文件 | 文件不存在时返回非零退出码 |
| TC-08 | tail 空文件 | 空文件返回零退出码，stdout 为空 |
| TC-09 | tail 跟随新增数据 | `tail -f` 在后台运行，追加新数据后被捕获到 stdout |

## 5. 与其他场景的依赖关系

无依赖，可作为独立场景运行。本场景仅使用 `common.LogGenerator` 生成测试数据，不依赖 MockKafka 或 `log-reader` 进程。
